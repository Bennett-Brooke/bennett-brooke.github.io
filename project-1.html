Terrain & Imagery Analysis

GEOG 392 Lab 7 — Python / arcpy raster workflow

Problem

Derive terrain and vegetation products from elevation and satellite imagery using a single, reproducible script: a hillshade and slope layer from a DEM, an RGB composite from Landsat bands, and an NDVI raster. [1]

Data & method

Data:

  • DEM: n30_w097_1arc_v3.tif (1-arc-second DEM) [1]
  • Landsat 5 scene LT05_L2SP_026039_20110803 — surface-reflectance bands B1 (blue), B2 (green), B3 (red), B4 (NIR) [1]

Method (arcpy):

  • Set arcpy.env.overwriteOutput = True and built output paths relative to the script directory for reproducibility. [1]
  • Generated a hillshade with arcpy.ddd.HillShade (azimuth 315, altitude 45, no shadows, z-factor 1). [1]
  • Generated a slope layer in degrees with arcpy.ddd.Slope. [1]
  • Built an RGB composite with arcpy.management.CompositeBands. [1]
  • Computed NDVI as ((NIR − Red) / (NIR + Red)) × 100 + 100 and saved it as a raster. [1]
