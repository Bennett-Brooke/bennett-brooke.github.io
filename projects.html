Hillshade & Hypsometric Cartography — GEOG 395 Lab 7

Cartographic design in ArcGIS Pro

Designed a poster-quality topographic map using a multidirectional hillshade (z-value 2), a percent-clip stretch for the hypsometric tint, and 50-ft contours with 250-ft index contours for a park audience familiar with the area.

Kaibab Deer System Dynamics Model — GEOG 467 Lab 8

System-dynamics modeling in Vensim

Built fourth and fifth Vensim models of the Kaibab deer case study (1900–1940), modeling deer population against forage biomass and predation; the fifth model added an old-biomass nutrition factor to the forage-needs calculation.

Spatiotemporal Visualization of Hurricans

ArcGIS Pro Python Toolbox · December 2025

Designed a small-multiples map using thematic cartography principals in ArcGIS Pro showing Atlantic hurricane intensity and paths from 1950 to 2023. Wrote Arcade expressions to classify storm intensity, displayed using differing line widths and a sequential color scheme.
